Annotated transcript

A search result becomes a recoverable agent-session transcript.

The transcript below follows real ctx commands and output shapes. The content is sanitized from a local search for flake, but IDs, fields, ranking, next-command hints, and transcript layout mirror actual CLI output.

1. Search local history

--refresh off asks ctx to use the current local index without doing a best-effort provider refresh first. --limit 1 --verbose prints full ctx IDs and copyable next commands.

$ ctx search flake --refresh off --limit 1 --verbose

  ctx_event_id: ffd00d29-6b15-750a-824a-bd9666fa8959

  provider_session_id: ses_0d0ac8b4fffe6JoiJHNBUsCtw7
  source_format: opencode_sqlite
  tool call: bash
input: {"command":"jj diff --no-pager -r @ flake.lock | rg '^\\+' ...","timeout":120000,"workdir":"/Users/chris/dotfiles"}

2. Inspect the session

The next: hint opens the full transcript. The header tells you which provider produced it, where it came from, and the provider-owned session ID for cross-checking.

$ ctx show session dde78c21-2fa4-7d04-9b5e-06c434bca647
ctx_session_id: dde78c21-2fa4-7d04-9b5e-06c434bca647
provider: opencode
provider_session_id: ses_0d0ac8b4fffe6JoiJHNBUsCtw7
mode: lite
format: text
source_path: /Users/chris/.local/share/opencode/opencode.db

3. Narrow within the same session

Once a session looks relevant, a scoped search returns dense hits from that one transcript instead of diverse results across the whole index.

$ ctx search flake --session dde78c21-2fa4-7d04-9b5e-06c434bca647
